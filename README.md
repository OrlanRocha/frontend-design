# Frontend Design para Codex

Adaptação independente da [skill frontend-design da Anthropic](https://github.com/anthropics/skills/tree/main/skills/frontend-design), com ajustes para orientar o Codex em novas interfaces e mudanças visuais em produtos existentes.

## Uso

Instale a pasta deste repositório como `frontend-design` no diretório de skills do Codex. Se já houver uma instalação com esse nome, preserve uma cópia antes de substituir os arquivos. Acione com `$frontend-design` seguido do pedido.

A skill adapta o planejamento ao tamanho da mudança, preserva os padrões existentes e orienta a revisão visual e funcional no navegador. Inclui exemplos para uma mudança pontual em configurações e uma nova landing page.
